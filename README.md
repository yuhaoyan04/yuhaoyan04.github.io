# Yuhao Yan — Personal Research Portfolio

Source for [yuhaoyan04.github.io](https://yuhaoyan04.github.io/), a bilingual research portfolio covering:

- point-in-time A-share quantitative research;
- LLM pretraining and YuFormer;
- embodied AI and robotics;
- Android and knowledge-system development;
- internships, education, and honors.

The site is a dependency-free static academic homepage with a responsive layout, accessible navigation, and no third-party runtime assets or animation scripts.

## Local preview

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

GitHub Pages publishes the `main` branch at the repository root. The `.nojekyll` file keeps the site fully static.
