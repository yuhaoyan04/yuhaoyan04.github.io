A 股点时多因子、模型比较与执行审计

2026 — 至今

独立研究 · Python / PIT / Purged walk-forward / Execution audit

  • 构建覆盖 2006–2026 年、5,521 只历史股票和约 1,479 万行特征的点时研究管线，以证券快照、信息可用日和分区审计控制幸存者偏差与前视偏差。
